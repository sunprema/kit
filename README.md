# kit

A Claude Code plugin marketplace for authoring tools. One repo, one sibling
directory per plugin — install the marketplace once, then install just the
plugin(s) you want.

```
/plugin marketplace add sunprema/kit
/plugin install bookbank@kit
```

Nothing here is tied to one account. The plugins write books and courses into
**your** repo, publish to **your** GitHub Pages site, and commit as **you** —
see [Setup](#setup).

## Plugins

- **[`bookbank/`](bookbank/)** — research-and-write BookBank books, publish
  them to your own GitHub Pages library, and generate a book from a
  GitHub Issue. See [`bookbank/docs/contributor-setup.md`](bookbank/docs/contributor-setup.md).
- **[`coursebank/`](coursebank/)** — generate an interactive training course
  from a source corpus (a repo, docs, or policies) as an installable
  offline-first PWA — lessons, checkpoints, tracked progress, and a
  completion certificate. Requires `bookbank` for its craft skills. See
  [`coursebank/docs/design.md`](coursebank/docs/design.md). Local generation
  works today; the publish half ("the academy") isn't built yet.

(More plugins land here over time — each lives in its own top-level
directory, listed in `.claude-plugin/marketplace.json`. `dashbank/` is a
work-in-progress and is deliberately **not** listed yet, so it can't be
installed.)

## Setup

Create a public repo for your books, enable Pages (Settings → Pages → `main` /
root), and work inside a clone of it — `/write-book` and `/publish-library`
derive everything from that clone's `origin` remote, so **the common case needs
no configuration**:

```sh
gh repo create <owner>/books --public --clone && cd books
```

There is deliberately no baked-in default repo: config can only resolve to the
clone you're actually in, so a fresh install can't publish into someone else's
library. Set these only when you're working outside the clone, or want to
override:

```sh
export BOOKBANK_BOOKS_REPO="<owner>/<name>"    # when not inside the clone
export BOOKBANK_ROOT="$HOME/bookbank"          # optional: local data root
export BOOKBANK_SITE_URL="https://…"           # optional: only for a custom domain
```

Full walkthrough:
[`bookbank/docs/contributor-setup.md`](bookbank/docs/contributor-setup.md). For
headless runs (cloud routines, CI), see
[`bookbank/docs/routines.md`](bookbank/docs/routines.md) and
[`bookbank/docs/publish-on-merge.md`](bookbank/docs/publish-on-merge.md).

### Requirements

- **Claude Code**, and `gh` authenticated (`gh auth status`) for publishing.
- **Python 3** — the validator and library builder. No pip packages required;
  Pillow is used if present.
- **A Chromium-family browser** for cover rendering and visual QA. Auto-detected;
  override with `CHROME_BIN=/path/to/chrome`.
- **Node/npx** — only for the optional three.js bundle in WebGL figures.
- Optional: `cwebp` or Pillow for WebP encoding. macOS-only `sips` paths degrade
  gracefully elsewhere (you lose the share-preview JPEG, nothing else).
